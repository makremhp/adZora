# adZora

منصة إعلانات عربية مستقلة قيد التطوير، تربط بين المعلنين والناشرين مع واجهة عربية RTL وتجربة Mobile First.

## الحالة الحالية

- ✅ صفحة تسويقية عربية متجاوبة.
- ✅ توحيد الهوية الظاهرة إلى adZora.
- ✅ استخدام خط Tajawal للواجهة العربية.
- ✅ قائمة Navbar متجاوبة للهاتف مع الإغلاق عند اختيار رابط أو الضغط خارجها أو استخدام Escape.
- ✅ تحسين لوحة المعلن على الهاتف: الإحصائيات وجدول الحملات يتكيفان مع العرض الصغير.
- ⚠️ تسجيل الدخول الحالي تجريبي ولا يوجد Backend أو قاعدة بيانات بعد.
- ⚠️ أرقام الحملات والإحصائيات الحالية بيانات عرض وليست مصدرًا حقيقيًا.

## آخر ما تم إنجازه

### تحسين لوحة المعلن للهاتف

- منع لوحة التحكم من التسبب في تمرير أفقي على الهاتف.
- تحويل جدول الحملات إلى صفوف شبيهة بالبطاقات عند عرض الهاتف.
- إضافة تسميات واضحة لكل قيمة داخل صف الحملة.
- ترتيب رأس اللوحة وبطاقة الحساب والإحصائيات بشكل مناسب للشاشات الصغيرة.
- جعل زر إضافة حملة بعرض كامل على الهاتف.

## ما لم يتم بناؤه بعد

- نظام حسابات حقيقي وصلاحيات admin وadvertiser وpublisher.
- Backend وREST API وقاعدة PostgreSQL.
- إنشاء الحملات وإدارتها فعليًا.
- Publisher Panel وAd Zones.
- Ad Server وTracking.
- Ledger والمدفوعات وطلبات السحب.
- لوحة الإدارة ومراجعة الحملات والمواقع.
- Analytics حقيقية ومكافحة الاحتيال.

## الخطة المرحلية التالية

1. تقسيم واجهة لوحة المعلن إلى أقسام واضحة مع الحفاظ على Mobile First.
2. بناء نموذج إنشاء حملة متجاوب كخطوة واجهة فقط.
3. إضافة Backend وقاعدة البيانات بعد تثبيت تجربة الواجهة.
4. ربط المصادقة والصلاحيات بالبيانات الحقيقية.
5. بناء Publisher Panel ثم Ad Server وTracking.

## ملاحظات مهمة

هذا المشروع يطوّر على مراحل صغيرة. كل تعديل يجب أن يحافظ على الهاتف والكمبيوتر، وأي أرقام مالية أو إحصائيات حقيقية يجب أن تأتي لاحقًا من الخادم وليس من localStorage أو بيانات ثابتة في الواجهة.


### نموذج إنشاء الحملة — واجهة أولية

- ✅ إضافة نافذة إنشاء حملة داخل لوحة المعلن.
- ✅ الحقول الأساسية: الاسم، نوع التسعير، نوع الإعلان، الميزانيات، سعر العرض، الاستهداف، والأوقات.
- ✅ تصميم متجاوب للهاتف والكمبيوتر مع نافذة قابلة للتمرير عند الحاجة.
- ✅ إضافة رسالة واضحة بأن النموذج تجريبي ولا يحفظ بيانات حقيقية بعد.
- ⏳ الخطوة التالية: ربط النموذج بالـAPI والتحقق Server-Side وحفظه كمسودة في قاعدة البيانات.
